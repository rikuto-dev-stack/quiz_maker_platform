# 要件整理（MVP）

## 利用者
自分専用の学習ツール（他人との共有は想定しない）

## 技術スタック
- フロントエンド: TypeScript
- バックエンド: Python（未定：フレームワークは今後決定）
- データベース: PostgreSQL（後日導入）

## 出題形式
- 選択式（4択、正解は1つ、解説文なし）

## 問題の構造
- フラットな1階層構造（問題集 → 問題）

## ログイン機能
- なし（最初はブラウザのlocalStorageにデータを保存）

## 復習機能
- クイズ終了後、「間違えた問題だけ復習」できる（履歴保存はなし）

## 結果記録
- その場限り（スコア表示のみ）。過去の成績履歴保存はデータベース導入後に対応

## 編集・削除機能
- なし（まずは新規作成のみ対応）

## MVPで最低限できること
1. 問題集を新規作成できる
2. 問題集の中に、選択式の問題（4択）を追加できる
3. 問題集を選んで、クイズを実施できる
4. クイズ終了後、スコア（◯問中◯問正解）が表示される
5. 間違えた問題だけをもう一度解き直せる

# 画面遷移
```
[ホーム画面]
│
├─(「新しい問題集を作る」ボタン)──→ [問題集作成画面]
│                                        │
│                                (名前を入力して確定)
│                                        ↓
│                                 [問題追加画面]
│                                        │
│                          (1問保存するたびにフォームをリセットし、
│                           続けて次の問題を入力できる)
│                                        │
│                              (「完了」ボタンを押す)
│←───────────────────────────────────────┘
│
├─(一覧から問題集を選ぶ)──→ [クイズ実施画面]
│
(全問回答し終わる)
↓
[結果画面]
│        │
(間違えた問題だけ復習) (ホームに戻る)
↓        │
[クイズ実施画面]   │
↓
[ホーム画面]

```
